# 1.1.6

这一版两端共 9 处改动，主要是**更新提醒**和**公告**两套机制，外加一批数据正确性与交互修复：

- **更新提醒**：打开软件就检测，有新版本才提示，关闭只对本次运行有效
- **公告**：启动只弹未读，桌面侧栏 / 安卓「我的」里可回看
- **桌面端用量页**：消耗曲线补真实日期轴与带日期的峰值、请求日志修正密钥与 Token 列、通道角标与通道页统一数据源
- **桌面端设置页**：新增手动检查更新
- **安卓端**：折线可点选查看单日数值、检查更新改为「先提示再跳转」按钮、启动闪屏改纯色

## 两端共有

### 打开软件就检测新版本

启动时查一次 GitHub Releases 的最新版本号，和当前版本比对：

- **有新版本**：顶部出现一条提示，写明新版本号和当前版本，带「前往下载」和关闭按钮
- **没有新版本**：什么都不显示，不会出现「已是最新」这类无意义横幅
- **查不到**（断网、GitHub 不可达）：同样什么都不显示，网络抖动不该变成每次启动的报错条

这次修掉的关键问题是**检测时机**：之前这段逻辑挂在登录之后的界面里，带着已保存登录状态冷启动时，若先停在登录页就完全不检测，看起来像功能坏了。现在它挂在应用最外层，登录页也会检测。

### 关闭只是「这次先不看」

点 × 只对本次运行生效，当次不再出现；**下次打开软件，只要新版本还在，提示会照常出现**。

之前是把这个版本号写进本地存储、永久不再提示，结果点错一次就等于永久静音。旧的持久化记录会在启动时清掉一次。

### 公告

- 启动只弹**未读**公告，读过的不再弹
- 弹窗右上角有 ×，「我知道了」与 × 等效，两者都标记为已读
- 另有「不再提示该公告」，这条是真的不再提示，和关闭窗口是两回事
- 桌面端左侧边栏在「今日消耗」**上方**多一个「查看公告」入口，带未读数，点开可回看全部并「全部标为已读」
- 安卓端在「我的 → 公告」显示未读标记与「全部已读」

## Windows 桌面端

- **用量页消耗曲线**：补上真实日期轴（首、中、尾三个时间点），峰值读数带上具体日期，不再只有一个孤零零的金额；鼠标悬停时中间那格显示当天日期和金额
- **请求日志**：之前密钥列和 Token 列取错了字段，真实数据里这两项是有返回的。现在按 `api_key_name` / `key_name` / `token_name` 等实际字段名解析，取不到时显示 `—` 而不是假 `0`
- **通道角标**：侧边栏通道旁边的红色数字和通道页里的「异常通道」数值不一致，原因是两处各自缓存、更新时间不同。现在统一读通道页那份快照
- **设置页检查更新**：关于面板里有手动「检查更新」，显示「已是最新版本」或「发现新版本 + 前往下载」，失败时按钮变成「重试」

## Android 端

- **折线可以点**：概览和用量的消耗曲线支持点选 / 拖动，点哪天就显示那天的日期和金额，标题跟着切换；中间槽位只放当前读数，不会和两侧日期标签挤成一串
- **检查更新改为两步**：「关于 → 检查更新」原来一检测到新版本就直接跳出浏览器，现在先显示「发现新版本 x.y.z」，下方才出现「前往下载 x.y.z」按钮，由你决定要不要跳
- **启动闪屏**：去掉了启动时一闪而过的白底加图标画面。之前生成的启动图是一张 1152×1152 白底图配 `#FFFFFF` 背景，所以每次冷启动都会闪一下亮色再进深色界面。现在启动图是纯 `#07080D`、不带图
